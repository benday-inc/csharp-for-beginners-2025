# C# for Beginners 2025

Welcome to the official repository for the **C# for Beginners 2025** YouTube video series! This repository contains all the source code, examples, and downloadable resources that accompany the video tutorials.

## 📺 About This Series

This video series is designed to teach you C# programming from the ground up. Whether you're completely new to programming or coming from another language, this series will guide you through the fundamentals and help you build a solid foundation in C# development.

## 📚 What You'll Learn

- C# syntax and fundamentals
- Object-oriented programming concepts
- Working with variables, data types, and operators
- Control flow (if statements, loops, etc.)
- Methods and functions
- Classes and objects
- Collections and LINQ
- Error handling and debugging
- And much more!

## 🎯 Prerequisites

- A computer running Windows, macOS, or Linux
- No prior programming experience required!
- Enthusiasm to learn

## 🛠️ Setup Instructions

### Install the .NET SDK

1. Visit the [official .NET download page](https://dotnet.microsoft.com/download)
2. Download and install the latest .NET SDK for your operating system
3. Verify installation by opening a terminal/command prompt and running:
   ```bash
   dotnet --version
   ```

### Choose Your IDE

You can use any of these editors/IDEs:
- **Visual Studio** (Windows/Mac) - Full-featured IDE, recommended for beginners
- **Visual Studio Code** (Windows/Mac/Linux) - Lightweight, with C# extension
- **JetBrains Rider** (Windows/Mac/Linux) - Professional IDE

## 📂 Repository Structure

```
/

├── Lesson-03-Data-Types/

```

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/benday-inc/csharp-for-beginners-2025.git
   ```

2. Navigate to the lesson folder you want to explore:
   ```bash
   cd csharp-for-beginners-2025/Lesson-XX-TopicName
   ```

3. Open the solution/project in your preferred IDE or run it directly:
   ```bash
   dotnet run
   ```

## 📖 How to Use This Repository

- Each lesson folder contains a README with specific instructions
- Code is heavily commented to help you understand what's happening
- Try modifying the code and running it to see what happens!
- Complete the exercises to reinforce your learning
