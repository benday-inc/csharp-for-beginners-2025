# Code Samples for Title: Choosing Your Tools - Command Line to Visual Studio

This file contains all code samples from the video.

## Slide 8: Verifying Your Installation

```bash
# Check if .NET is installed
$ dotnet --version
8.0.100

# See all installed SDKs
$ dotnet --list-sdks
8.0.100 [C:\Program Files\dotnet\sdk]

# See available project templates
$ dotnet new list
```

## Slide 9: The Core Command Line Tools

```bash
dotnet new    # Create new projects
dotnet build   # Compile your code  
dotnet run     # Execute your program
dotnet test    # Run unit tests
dotnet publish # Prepare for deployment
```
